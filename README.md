# H2 Raman Temperature Fitter

## Overview

**H2 Raman Temperature Fitter** estimates gas temperature by comparing a processed experimental H2 Raman spectrum with simulated Raman spectra.

The program can:

- Load wavelength-calibrated experimental spectra
- Select wavelength and intensity columns
- Preview the experimental spectrum
- Detect or manually enter equivalence ratio (Phi)
- Calculate H2-air product gas composition
- Generate or load a compatible Raman simulation library
- Fit temperature, wavelength shift, and Gaussian broadening
- Report the best-fit temperature, shift, broadening, and fitting error
- Plot the experimental spectrum with the best-fit simulation

## Example Data

Example experimental spectrum files are included so the program can be tested without new measurements.

The included example spectra use experimental H2-air Raman data reported by **Litchford et al. (2006)**. These files are provided as test/validation inputs for the temperature-fitting workflow and are not generated by this program.

## Experimental Data Requirements

Input spectra should contain:

1. A wavelength column in **nanometers**
2. A **background-subtracted intensity** column

The wavelength must already be calibrated. The program does **not** currently convert detector pixels to wavelength, and experimental background subtraction should be completed before importing the data.

Small negative intensity values after background subtraction are generally acceptable if the Raman features remain visible.

Supported file types include:

```text
.csv
.txt
.dat
.xlsx
.xls
```

Text files may be comma-, tab-, or whitespace-separated.

Column numbering begins at **1**, similar to Excel. For a normal two-column file:

```text
Wavelength column: 1
Intensity column: 2
```

## Basic Analysis Workflow

1. Open the application.
2. Select the experimental spectrum.
3. Enter the wavelength and intensity column numbers.
4. Verify the spectrum preview.
5. Enter or verify Phi.
6. Select the fitting wavelength range.
7. Select the temperature range and temperature step.
8. Select the simulation generation wavelength range.
9. Select the wavelength grid increment.
10. Enable or disable wavelength-shift fitting.
11. Run the analysis.

The program crops and normalizes the experimental spectrum, calculates the gas composition, loads or generates a compatible Raman library, compares the simulated and experimental spectra, and selects the lowest-error fit.

## Equivalence Ratio

Phi is the hydrogen-air flame equivalence ratio:

```text
Phi < 1   Lean
Phi = 1   Stoichiometric
Phi > 1   Fuel-rich
```

The program may detect Phi from the filename, but the value should always be verified before analysis. Phi is used to determine the H2-air product gas composition used by the Raman model.

## Fitting Settings

### Fit Wavelength Range

This is the portion of the experimental spectrum compared with the simulations.

Example:

```text
296.7 to 299.5 nm
```

Choose a region containing useful H2 Raman structure while avoiding unrelated peaks, contamination, noisy edges, or other unwanted spectral features when possible.

### Generation Wavelength Range

This is the wavelength range over which simulated spectra are generated.

Example:

```text
296.0 to 300.2 nm
```

The generation range must fully contain the selected fit range.

### Temperature

Select the minimum temperature, maximum temperature, and temperature step.

A smaller temperature step provides finer resolution but requires more simulated spectra and increases generation time and library size.

### Gaussian Broadening and Wavelength Shift

The current fitting search uses Gaussian broadening values from:

```text
0.000 to 0.150 nm FWHM
```

When wavelength-shift fitting is enabled, the program searches:

```text
-0.10 to +0.10 nm
```

Gaussian broadening accounts for additional spectral broadening between the modeled and measured spectra. Wavelength shift allows small differences in spectral alignment.

For each tested temperature, broadening, and wavelength shift, the program calculates a fitting error. The combination with the lowest error is selected as the best fit.

### Wavelength Grid Increment

Common values include:

```text
0.01 nm
0.001 nm
0.0001 nm
```

A smaller increment produces a higher-resolution simulation grid but increases computation time, memory use, and library size.

## Generated Libraries

Generated Raman libraries are saved in:

```text
generated_libraries/
```

If a compatible library already exists, the program reuses it instead of generating a new one.

Library compatibility depends on settings such as:

- Phi and gas composition
- Excitation wavelength
- Temperature range and step
- Generation wavelength range
- Wavelength grid increment

A previously generated library may be reused when it contains the temperatures and wavelength range required for the new analysis.

## Results

The program reports:

- Best-fit temperature (K)
- Best wavelength shift (nm)
- Best Gaussian broadening (nm)
- Best fitting error
- Simulation library used

The final plot compares the processed experimental spectrum with the best-fit simulated Raman spectrum.

The reported temperature is a **model-based best-fit result** and depends on the experimental data quality, selected fitting region, simulation assumptions, and fitting parameter ranges.

## Troubleshooting

**Preview does not appear**
- Confirm a file was selected.
- Check that the wavelength and intensity columns are valid, different, and numeric.
- Confirm at least 10 valid data rows are available.

**Preview looks incorrect**
- Check the selected columns, wavelength units, file delimiter, and whether the data is still in detector pixels instead of nanometers.

**Fit range leaves too few points**
- Widen the fit range or confirm that the experimental data overlaps the selected wavelength range.

**Generation range does not cover the fit range**
- Expand the generation range so it fully contains the fit range.

**Library generation is slow**
- Large temperature ranges, small temperature steps, wide wavelength ranges, and very fine wavelength grids increase generation time.
- Once generated, compatible libraries can be reused.

**Best-fit temperature is at the minimum or maximum**
- Expand the temperature search range and run the analysis again.

**Experiment and simulation do not match well**
Possible causes include incorrect column selection, Phi, wavelength calibration, background subtraction, fitting region, temperature range, gas composition, instrumental broadening differences, experimental noise, or unrelated spectral features.
